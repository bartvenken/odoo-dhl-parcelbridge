Labels & Tracking for DHL eCommerce Benelux

Odoo delivery-method module. Creates the DHL label and tracker(s) when a delivery is validated.

What it does

  • Native delivery.carrier provider integrated with sale orders, Add Shipping wizard, website checkout and backorders.
  • All DHL parcel types: Envelope, Mailbox parcel, Parcel up to 10 / 20 / 31 kg, Pallet up to 1000 kg. Plus Mixed and Operator-picks-at-packing variants.
  • International DHL products (Parcel Connect, Europlus International, Parcel Connect 2C, Europlus Pallet) resolved automatically per destination country and recipient type.
  • Customs declaration added automatically for non-EU shipments (United Kingdom, Switzerland, Norway).
  • Multicollo via the Number of parcels field on the delivery, or via native Put in Pack for per-box weights.
  • Recipient-aware carrier filtering: consumer-only carriers hidden from business customers, business-only carriers hidden from consumers.
  • Test Connection button: authenticates against DHL, reports account, roles and token expiry.
  • Verify Contract button: for each enabled destination country and recipient type, checks whether the DHL product the module would use is active on your DHL contract.
  • Sandbox / production detection: warns if a test key is used in a carrier configured as production.
  • Debug bundle export on each delivery: JSON export of the full context with credentials redacted.
  • Access control: API credentials restricted to a dedicated DHL Parcel Administrator group.
  • Available in English, Dutch, French and German.
  • OPL-1 license (source-readable, redistribution not allowed).

How to use

  1. Install the module.
  2. Create a shipping method: provider = Labels & Tracking for DHL eCommerce Benelux. Fill in User ID, API Key, Account ID, pick a parcel type.
  3. Click Test Connection to confirm the credentials. Click Verify Contract to check the destinations against your DHL contract.
  4. Add Shipping on a sale order, pick the method, confirm.
  5. Validate the delivery. Label PDF and tracker(s) are attached to the picking automatically.

Requirements

  • Odoo 17.0, 18.0 or 19.0 (community or enterprise) with stock_delivery and sale.
  • An active DHL eCommerce Benelux account with API access activated on the contract. API access is not enabled by default; request it from your DHL contact.
  • Sender in Belgium, the Netherlands or Luxembourg.
